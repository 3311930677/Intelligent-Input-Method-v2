OwO 输入法 0.9.0（Windows x64 便携版）
========================================

开源地址：https://github.com/3311930677/Intelligent-Input-Method-v2
许可协议：GPL-3.0（见同目录 LICENSE）


一、安装
--------
双击 install.bat 即可，**不需要管理员权限**
（输入法注册写入 HKEY_CURRENT_USER，不动系统全局注册表）。

安装脚本做三件事：
  1. 用 regsvr32 注册 bin\OwO.TSF.dll
  2. 在当前用户「启动」目录创建 "OwO Core Service" 快捷方式，实现开机自启
  3. 立即启动后台服务

装完后用 Win+空格 切换到「OwO 输入法」。


二、重要提示（务必先读）
------------------------
* 词典约 65 MB，后台服务**首次加载需要十几秒**。
  这段时间候选栏可能没有候选，请稍等再开始打字。

* 后台服务 owo_core_service.exe 必须处于运行状态，否则打不出字。
  拼音分词与候选生成都在它里面完成，输入法本体只负责显示候选。
  判断是否加载完成：任务管理器里该进程内存占用达到 1 GB 以上即为就绪。

* 已经打开的程序需要重启才能加载新输入法，这是 Windows TSF 的限制。

* 请不要在安装后移动整个文件夹。开机自启快捷方式记录的是绝对路径，
  移动位置后需要重新运行一次 install.bat。


三、运行环境
------------
* Windows 10 1809（build 17763）或更高版本 / Windows 11，x64
* 需要 Microsoft Visual C++ 2015-2022 Redistributable (x64)
  绝大多数电脑已自带。若启动时提示缺少 VCRUNTIME140.dll 或 MSVCP140.dll，
  请到微软官网下载 vc_redist.x64.exe 安装。


四、目录说明
------------
  bin\OwO.TSF.dll         输入法本体（TSF 文本服务 DLL）
  bin\owo_core_service.exe    后台服务：拼音分词 + 候选生成
  bin\owo_config_shell.exe    配置命令行工具
  bin\owo_plugin_shell.exe    插件管理命令行工具
  bin\owo_voice_input_plugin.exe  语音输入后端（按 F9 时由后台服务调用，基于 Windows 语音识别）
  lexicon\*.owolx   编译后的二进制词典（RIME-ICE 中文词库）
  install.bat  安装
  uninstall.bat               卸载
  tools\           安装/卸载脚本本体
  LICENSE         GPL-3.0 许可证


五、功能说明
------------
  候选栏表情按钮    打开表情 / 颜文字 / 标点 / 数学 / 几何 / 货币 面板
     （已内置在本体中，无需安装任何插件）
  F9 语音输入   开始/停止语音识别，识别结果直接上屏（详见第七节前提）
  每页候选数     7（可用 owo_config_shell 调整）
  空格    上屏首选；候选请求失败时上屏原始拼音字面
  数字键 1-7        选择对应候选


六、卸载
--------
双击 uninstall.bat。会依次停止后台服务、移除开机自启项、注销输入法。
用户配置仍保留在 %LOCALAPPDATA%\OwO，如需彻底清除请手动删除该目录。


七、语音输入（F9）前提说明
--------------------------
语音后端已随本体内置（bin\owo_voice_input_plugin.exe），按 F9 即可使用，
但它调用的是 Windows 自带的语音识别（SAPI），因此需要满足两个前提：
  1. 系统已安装中文（zh-CN）语音识别包。
     「设置 - 时间和语言 - 语言 - 中文 - 语音」里可添加。
  2. 有可用的麦克风，且已允许桌面应用访问麦克风。
若缺少上述任一项，按 F9 会提示识别失败或「未安装中文语音识别」，
这属于系统语音组件缺失，并非输入法本身的问题。


八、已知限制（如实说明）
------------------------
* 表情与符号面板已内置在本体，不依赖插件即可使用。
* 插件库中的「特殊符号」尚无源码、「灵犀AI 辅助」仍在规划中。
* 本包未做代码签名，Windows SmartScreen 可能提示来源不明，
  可选择「更多信息」-「仍要运行」。也可自行按仓库源码编译核对。
