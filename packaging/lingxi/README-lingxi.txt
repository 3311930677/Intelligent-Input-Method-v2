灵犀 · AI 辅助输入系统（LingXi Overlay）预览版 0.1.0
======================================================

这是什么
--------
OwO 输入法的 L3 跨应用 AI 助手（预览版）。它是一个独立的桌面小程序，
和 OwO 本体配合使用：
  * 选中任意文字，按 Ctrl+Alt+Space，可做「润色 / 纠错 / 提示词增强」，
    预览字符级 Diff 后确认写回；
  * 可读取当前 QQ 聊天并生成一条回复草稿（写入输入框，绝不自动发送）；
  * 桌面右下角有一个桌宠，单击可显隐主面板。

** 已去除全局键盘钩子 **
本版本不再安装低级键盘钩子，不会拦截你打字。系统拼音输入完全由 OwO 本体
（TSF输入法）负责，灵犀只做「选区 AI 处理」，两者可同时开着、互不干扰。

运行前提
--------
1. Windows 10 / 11 x64。
2. Microsoft Edge WebView2 运行时：多数 Win10/11 已自带；若启动没有界面，
   到微软官网安装 “WebView2 Runtime (Evergreen)” 即可。
3. Microsoft Visual C++ 2015-2022 运行库 (x64)：多数电脑已有；若提示缺少
   VCRUNTIME140.dll，安装 vc_redist.x64.exe。
4. AI 功能二选一：
   - 本地模型：首次使用会联网下载约 1GB 的 Qwen2.5 1.5B 模型（之后缓存复用）；
   - 云端模型：在设置里填 OpenAI 兼容接口的 API Key（DeepSeek / 通义 / OpenAI /
     自定义 Endpoint 均可）。API Key 只保存在当前进程内，不写入任何文件。

使用
----
* 双击 run-lingxi.bat（或直接双击 overlay.exe）启动。
* Ctrl+Alt+Space   捕获当前选区并打开 AI 处理面板（预览 Diff -> 确认写回）。
* Ctrl+Alt+Backspace  撤销最近一次成功写回。
* 单击右下角桌宠     显示/ 隐藏主面板。

安全说明
--------
* QQ 回复草稿只写入输入框，发送必须由你手动确认，程序不会自动发送。
* 密码框等敏感控件的选区读写会被拒绝。
* 写回前会校验前台窗口与选区，目标漂移时拒绝写入，避免改错窗口。

已知限制（如实说明）
--------------------
* 预览 / 原型阶段，仅支持 Windows。
* AI 写回依赖 UIA / 剪贴板，少数限制模拟按键或剪贴板的应用可能无法写入。
* QQ 功能依赖 QQ 当前界面结构，QQ 更新后可能需要重新适配。
* 本包未做代码签名，Windows SmartScreen 可能提示“未知发布者”，
  点「更多信息 → 仍要运行」即可；也可按仓库源码自行编译核对。
