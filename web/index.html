全拼智能引擎

基于 Rime 词库 + beam search 与二元语法排序，支持缩写、纠错拼音与用户词频学习。

😊

表情面板

候选栏一键唤起分类面板，表情 / 颜文字可搜索、可网格浏览，点击直接上屏。已内置本体，无需插件。

🔣

特殊符号

标点、数学、几何、货币等符号分类，与表情面板同一入口，点击直接上屏。已内置本体，无需插件。

🎙️

语音输入

按 F9 调用系统中文语音识别，说话即上屏。已内置本体，需系统中文语音包与麦克风。

OwO 输入法

下载安装包 从 GitHub 获取源码 / 校验 或下载免安装便携版 ZIP（20.4 MB）
  1. 运行安装包：双击下载的 .exe。未做代码签名，若弹 SmartScreen 点「更多信息 → 仍要运行」。
  2. 按向导安装：不需要管理员权限，装完自动注册输入法并启动后台服务。
  3. Win+空格 切换：词典约 65 MB，后台服务首次加载需十几秒，稍等再开始打字。
  4. 表情/符号面板与语音输入(F9)已内置：装好即用，无需另装插件。
