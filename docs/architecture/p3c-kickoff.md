# 阶段启动单：P3C 插件框架基础

- 状态：已启动
- 日期：2026-08-01

## 本阶段边界

P3C 建立插件包、信任、权限、安装和进程隔离基础。首个切片只读取并严格校验 `manifest.json`；不解包 `.owopkg`、不安装、不启动插件、不开放网络，也不把插件代码加载进 TSF 或 Core Service。

## v1 可回滚决策

- `.owopkg` 预留为 ZIP 兼容容器，但在解包防护和签名覆盖范围验收前不实现读取。
- Manifest 是 UTF-8、无 BOM、最大 64 KiB 的封闭 JSON 子集；v1 字符串只接受原始 UTF-8 及引号、斜杠、反斜杠转义。未知字段、重复字段、尾随数据和未知权限失败封闭。
- MVP 仅接受 `runtime=process`、`api_version=1` 和安全的 `bin/*.exe` 相对入口。
- 权限仅接受总控提示词给出的五项白名单；`network=true` 在 v1 无条件拒绝。
- 未签名、签名无效或发布者不受信的软件包默认拒绝安装；开发模式例外必须显式启用并显示风险，后续切片实现。
- 插件安装目录、数据目录和暂存目录分离；可执行目录不可写入运行数据，也不得加入进程 DLL 搜索路径。

## 首个切片验收条件

- 有独立 `owo_plugin` 静态库，不进入 TSF DLL 或 Core Service 依赖图。
- 合法最小 manifest 可解析；路径穿越、未知字段、重复字段、未知权限、网络请求和不兼容版本均被拒绝。
- 默认 Release 构建和全量 C++ 回归通过。

## 后续切片

1. 固定 ZIP 解包限制、文件清单与抗路径穿越规则。
2. 固定规范化哈希、签名覆盖范围和 Windows 信任验证方案。
3. 实现原子安装/更新/回滚和独立插件数据目录。
4. 定义版本化 PluginHost IPC、权限授权记录、超时、取消和进程资源限制。
