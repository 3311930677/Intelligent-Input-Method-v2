# 插件权限与包格式草案

- 包扩展名为 `.owopkg`，采用 ADR 0008 定义的受限 ZIP 兼容容器、规范化清单与 Windows 发布者信任链。
- 开发阶段允许开发者模式加载未发布包，但必须有持续可见提示；发布策略默认要求可信签名。
- `runtime=process` 为 MVP 首选；不可信插件不得进入 TSF 或 Core Service 地址空间。
- 权限逐项声明且默认拒绝；权限升级必须重新确认。
- 授权记录按 ADR 0011 绑定精确插件版本、包清单摘要和发布者证书；每次敏感操作仍须核对当前 manifest，旧授权不得跨绑定继承。
- 授权记录按版本原子写入独立目录；缺失、损坏、schema 未知或与安装记录不一致时一律视为零授权。
- 网络默认关闭，文件默认仅允许插件自己的数据目录。
- 包安装必须防路径穿越、大小炸弹、重复 ID 和清单欺骗。
- 更新采用暂存、完整性验证、原子切换和可回滚流程。

容器与信任决策见 ADR 0008，版本化存储见 ADR 0010，PluginHost 内部契约和授权格式见 ADR 0011。自动更新源仍未冻结。
