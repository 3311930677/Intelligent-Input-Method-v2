# ADR-0004：词库来源、许可与构建边界

- 状态：P2 临时接受
- 日期：2026-07-31

## 背景

P2 计划使用雾凇拼音词库，但 OwO 仓库当前没有项目许可证文件。雾凇拼音官方仓库当前标注为 GPL-3.0-only，发布资产包含独立许可文件。源词库、清洗后中间文件和派生二进制的分发边界必须在导入前明确。

## 决策

1. P2.2 先实现与具体上游解耦的词库编译器、版本化二进制格式和严格读取器。
2. 功能和损坏测试使用仓库内最小项目测试数据，不声明它是雾凇词库子集。
3. 在 OwO 项目许可和 GPL 分发策略明确前，不下载、不提交、不随构建产物分发完整雾凇源词库或派生二进制。
4. 未来导入必须锁定不可变提交 ID 或发布标签，记录下载 URL、SHA-256、许可标识和导入器版本。
5. 构建工具对缺失来源 manifest、未知格式版本、非法 UTF-8、越界字段和重复冲突失败封闭。

## 影响

- 可以在不承担未审核外部数据的情况下完成紧凑词典技术闭环。
- P2 的“雾凇词库构建工具”在通用编译器之后仍有一项许可决策门禁；未通过前不得宣称完整雾凇数据已集成。
- 本 ADR 不是法律意见；对外分发前仍需开发者确认项目许可策略。

## 回滚

删除外部导入适配器和相关 manifest 即可；通用词典格式、读取器与项目测试夹具不依赖雾凇数据。
